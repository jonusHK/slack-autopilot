# slack-autopilot

슬랙 채널에 적은 개발 지시를 클라우드 루틴이 매시간 주워서 **답하거나, 구현해 PR 로 만들거나,
사람에게 되묻는** 범용 엔진. 사람이 하는 일은 셋뿐이다.

| | 사람이 하는 일 | 그러면 |
|---|---|---|
| ✍️ | 채널에 지시를 불릿으로 쓴다 | 아직 아무 일도 없다 |
| ▶️ | 그 메시지(또는 스레드 답글)에 ▶️ 를 단다 | 다음 정각에 봇이 집는다 |
| 🚀 | 봇이 올린 PR 을 읽고 PR 링크 답글에 🚀 를 단다 | 다음 :30 에 봇이 병합한다 |

▶️·🚀 는 **사람만** 달 수 있다 — 봇이 달려고 하면 코드가 예외로 막는다(D-002). 그래서 봇이
자기 일을 스스로 다시 시작하는 루프가 구조적으로 생기지 않는다. 허용 목록 밖의 사람이 단
▶️·🚀 도 없는 것으로 본다(D-010).

## 한눈에

```mermaid
flowchart LR
    H["사람: 지시 + ▶️"] --> D{"검출<br/>매시 :00"}
    D -->|"할 일 없음"| Z["즉시 종료"]
    D -->|"있음"| C["💬 클레임"]
    C --> T{"불릿마다 분류"}
    T -->|"Q 설명만 구함"| QA["근거 붙여 답변 → ✅"]
    T -->|"A 스펙 확정"| IM["구현 → CI 그린 → PR → 📬"]
    T -->|"B 재량 있음"| BQ["판단 지점 질문 → ❓"]
    BQ -. "사람이 답글로 결정 + ▶️" .-> D
    IM --> HU["사람이 PR 검토 → 🚀"]
    HU --> MG["병합 루틴 매시 :30<br/>순차 병합 → ✅"]
```

**❓ 는 막다른 길이 아니라 대기열이다.** 사람이 결정 한 줄을 답글로 적고 ▶️ 를 달면, 그 답글이
새 지시가 되어 처음으로 돌아간다. 재량(B)이 스펙(A)으로 바뀌는 이 길이 시스템의 처리량을 정한다.

## 무엇이 어디에

```mermaid
flowchart TB
    subgraph SL["슬랙 — 상태"]
        MSG["메시지·스레드<br/>이모지 = 진행 상태"]
    end
    subgraph CL["클라우드 — 실행"]
        TR["트리거 2개<br/>:00 구현 · :30 병합"]
        VM["매번 새 VM<br/>아무것도 기억 안 함"]
    end
    subgraph EN["이 레포 — 방법"]
        BIN["bin/*.py<br/>결정적인 것"]
        PRM["prompts/*.md<br/>판단하는 것"]
    end
    subgraph TG["대상 레포 — 기준"]
        POL["AUTOMATION.md"]
        CI["CI"]
    end
    TR --> VM
    VM -->|"clone"| EN
    VM <-->|"이모지·답글"| SL
    VM -->|"브랜치·PR"| TG
    POL -. "티어 경계·금지선" .-> VM
    CI -. "결과만" .-> VM
```

| | 어디 | 무엇 |
|---|---|---|
| **엔진**(범용) | 이 레포 | 상태 기계·검출·락·자기 수정·병합 절차 |
| **정책**(프로젝트별) | 각 대상 레포의 `AUTOMATION.md` | 티어 경계·검증·병합 금지선·결정 기록 규칙 |
| **검증** | 대상 레포의 CI | 테스트·e2e. 엔진은 결과만 읽는다 |
| **실행** | 클라우드 루틴(cron) | 매시 폴링. 유휴면 즉시 종료 |

## 설계의 축

- **상태는 슬랙에 있다.** 루틴은 매 실행이 새 세션이고 아무것도 기억하지 않는다. 이모지가
  상태라, 어느 실행이 죽어도 다음 실행이 같은 이모지를 보고 그 자리에서 잇는다.
- **사람의 입구는 둘뿐이다.** ▶️(진행)·🚀(병합). 봇은 이 둘을 코드로 막혀 못 붙인다.
- **유휴가 기본이다.** 실행의 대부분은 "할 일 없음 → 즉시 종료"다. 할 일이 있는지부터 보고
  나서야 명세를 읽는다.
- **재량은 사람에게.** 봇은 무엇을 할지가 정해진 것만 구현한다. 병합은 🚀 뒤에만 한다.

## 새 프로젝트 붙이기

```mermaid
flowchart LR
    N["새 레포"] --> A1["AUTOMATION.md 작성<br/>필수 섹션 6종"]
    A1 --> A2["환경변수 추가<br/>SLACK_CHANNEL_ID_X · TARGET_REPO_X"]
    A2 --> A3["AUTOPILOT_PROJECTS 에<br/>접미사 X 추가"]
    A3 --> OK["끝 — 트리거는 그대로"]
```

엔진을 고쳐야 했다면 분리가 샌 것이다(D-001 ④). 루틴은 선언된 프로젝트를 전부 순회하므로
트리거를 새로 만들지 않는다(D-011).
